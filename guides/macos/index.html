macOS 苹果电脑 Clash Verge Rev 与 Surge 配置教程

📅 更新时间: 2026-11-15 ⏱️ 预计阅读: 7 分钟 🎯 适用系统: macOS 客户端教程
💡 教程前置说明

专为 Mac (M1/M2/M3/M4 Apple Silicon 及 Intel 机型) 用户量身定制的加速指南，推荐使用 Clash Verge Rev 与 Surge for Mac，保障 Safari 与生产力软件流畅访问海外网络。

1. macOS 平台客户端推荐

Mac 系统的网络架构与 Windows 有所不同，目前体验最佳的两个选择是：
1. Clash Verge Rev (Mac 版)：开源免费，完美原生支持 Apple Silicon (arm64) 与 Intel (x64) 芯片，资源占用极低；
2. Surge for Mac：苹果生态顶尖网络神器，具备强大的网关接管、进程级规则、DNS 优化与极度优美的界面（商业收费软件）。

2. Clash Verge Rev on macOS 安装与配置

步骤一：安装应用
下载对应的 .dmg 镜像文件（M 系列芯片下载 aarch64.dmg，Intel 芯片下载 x64.dmg），拖拽至【应用程序 (Applications)】文件夹。
首次打开若提示“无法验证开发者”，前往系统【设置】→【隐私与安全性】→ 点击【仍要打开】。

步骤二：拉取机场订阅
点击左侧【订阅】页面，粘贴机场提供的 Clash 格式订阅 URL，点击下载并选中配置。

步骤三：开启系统代理与权限授予
在【设置】界面打开【系统代理】开关。为了使终端命令行、Git 等开发工具也能顺畅通过代理，建议在高级设置中安装 Service 核心组件并开启 TUN 模式。

常见配置问题排查 (FAQ)

Mac 终端 (Terminal / iTerm2) 为什么用不了代理？+
终端默认不继承 macOS 图形界面的系统代理设置。解决办法有两个：1. 在 Clash Verge 中开启【TUN 模式】虚拟网卡；2. 在终端配置文件中设置 export http_proxy=http://127.0.0.1:7890 环境变量。
📌 还没有可用机场订阅？

本教程需要配合正规机场的订阅链接方可连接生效。
