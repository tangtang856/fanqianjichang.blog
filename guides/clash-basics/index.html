1. Clash 的三种核心运行模式深度解析

在使用任何基于 Clash 内核的客户端时，你都会看到三种模式切换：
  • Rule (规则分流 - 推荐默认)：根据预设的规则列表智能判断访问目标。国内网站（如百度、淘宝、B站）自动走 Direct 直连；国外网站（如 Google、YouTube、GitHub）自动走所选节点；流媒体或 AI 网站走特定指定节点。
  • Global (全局代理)：所有经过本机的流量全部无差别通过选中的代理节点发送。仅用于某些极特殊海外服务检测 IP 时临时使用，日常开启会导致访问国内网站变慢或提示异地登录。
  • Direct (完全直连)：不通过任何代理，等同于关闭代理客户端。

2. 什么是订阅转换？是否有安全风险？

很多机场只提供原生的 VMess / Shadowsocks 单节点连接串，需要转换为 Clash 能够读取的 YAML 配置文件。市面上存在很多公开的第三方在线订阅转换工具。
安全警示：将你的订阅链接提交给不受信任的第三方公开订阅转换网站，存在订阅链接被抓取、节点被偷跑盗用的风险。建议尽量选择机场原生直接生成的 Clash 订阅链接，或者自行使用本地 Subconverter 工具进行离线转换。
